# Contribuir

¡Gracias por el interés! Para colaborar:

1. Haz un *fork* y crea una rama (`git checkout -b mi-mejora`).
2. Instala dependencias con `npm install` y arranca con `npm start`.
3. Antes de abrir el *pull request* ejecuta:

   ```bash
   npm run check      # sintaxis
   npm run validate   # el mapa debe seguir siendo completable
   ```

4. Si cambias el mapa (`public/world.js`), explica en el PR qué habilidad abre cada puerta nueva.
5. Describe qué cambia y cómo lo has probado.

## Estilo

- Código sin dependencias nuevas salvo que haya una razón clara.
- Textos del juego en español.
- Cambios pequeños y enfocados.

## Errores y sugerencias

Abre un *issue* con los pasos para reproducirlo, el navegador y, si es online, si eras anfitrión.
